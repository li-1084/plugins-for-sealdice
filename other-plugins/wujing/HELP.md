# WuJing Help

`WuJing` 的完整中文帮助文档。

## 安装

1. 下载 `wujing.ts`。
2. 在 SealDice 中上传并加载脚本。
3. 需要使用武经模板时，可执行 `.set uj`。

如果你只是想先确认插件有没有正常加载，可以直接执行 `.ujhelp`。

## 快速开始

1. 用 `.set uj` 切换到武经规则模板。
2. 用 Sealdice 标准 `.st` 语法录入属性。
3. 用 `.ujs` 查看自己的名帖。
4. 用 `.uj <属性>` 进行属性投掷，或用 `.uj <数量>` 直接指定骰池。
5. 需要额外加算成功数时，用 `.uj <属性或数量>+<助力>`。
6. 需要调整群内文本表现时，用 `.ujflavor`。

## 指令速查

- `.set uj`
  - 切换到武经规则模板。
- `.ujs`
  - 查看自己的名帖。
- `.ujs @某人`
  - 查看他人的名帖。
- `.uj <属性>`
  - 使用属性进行投掷。
- `.uj <数量>`
  - 按指定骰池数量进行投掷。
- `.uj <属性|数量>+<助力>`
  - 在投掷后额外加算成功数，例如 `.uj jin+3`。
- `.uj @某人 <属性>`
  - 为他人代投属性检定。
- `.uj @某人 <数量>`
  - 为他人代投指定骰池。
- `.ujflavor list`
  - 查看当前可配置的批注与模板文本。
- `.ujflavor set <键名> <文字>`
  - 设置指定键名。
- `.ujflavor reset <键名>`
  - 重置指定键名。
- `.ujflavor reset all`
  - 重置全部风味文字。
- `.ujhelp`
  - 查看插件内置速查帮助。

## 详细说明

### 角色属性

- 武经规则当前使用的核心属性有：
  - `筋肉`
  - `灵巧`
  - `坚毅`
  - `悟性`
  - `六识`
  - `运气`
  - `气质`
- `根骨等级` 会保存在角色卡里，但不能直接用于检定。

### 投掷方式

- `.uj <属性>` 会读取该角色当前属性值，按属性值建立骰池。
- `.uj <数量>` 会直接以给定数字作为骰池大小。
- 当前默认使用 `D10` 骰，单骰结果大于等于 `7` 记为一次成功。
- 最终成功数大于 `0` 即视为成功，否则视为失败。

### 助力写法

武经插件支持三种助力输入方式，本质上都会在投掷完成后额外加上成功数：

- 紧凑写法：`.uj jin+3`
- 半分写法：`.uj jin +3`
- 全分写法：`.uj jin + 3`

如果你输入的是数字骰池，同样适用：

- `.uj 5+2`
- `.uj 5 +2`
- `.uj 5 + 2`

### 代投

- `WuJing` 支持代投。
- `.uj @某人 <属性>` 会读取被代投对象的属性值进行投掷，并在结果里显示目标玩家名。
- 如果是纯数字骰池，也可以使用 `.uj @某人 <数量>`。
- 当你只输入了 `@某人` 却没有给出属性或数量时，插件会提示补全参数。

### 风味文字与模板

- `.ujflavor` 用于管理群内的风味文字和输出模板。
- 除了属性风味外，投掷结果模板、帮助文本、错误提示等也都可以调整。
- 建议先用 `.ujflavor list` 看当前有哪些键，再决定要覆盖哪一项。
- 配置按群保存，不会影响其他群。

## 规则特点

- 支持属性别名输入。
- 支持助力投掷，兼容紧凑、半分与全分三种写法。
- `根骨等级` 保留在角色卡中，但不可直接用于检定。
- 风味文字与输出模板均可通过 `.ujflavor` 在群内覆盖。
- 投掷结果模板支持显示玩家名。

## 常见问题

### 可以直接 `.uj 根骨` 吗？

不可以。`根骨等级` 会保留在名帖里，但插件明确禁止拿它直接检定。

### 助力是增加骰子数量，还是增加成功数？

是增加成功数，不是增加骰池大小。也就是说，先正常投掷，再把你输入的助力值加到成功数上。

### 为什么文档里写 `.set uj`？

因为插件注册了武经规则模板，切换后可以让角色卡属性和该规则更贴近。即使不切换模板，插件本身的 `.uj` / `.ujs` / `.ujflavor` 指令也仍然是插件的主要入口。

### `.ujhelp` 和这份帮助文档有什么区别？

- `.ujhelp` 适合在聊天窗口里快速查看核心指令。
- 这份帮助文档负责给出更完整的说明，包括属性、助力、代投和风味配置说明。
